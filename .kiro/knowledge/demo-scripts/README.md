# Demo Scripts

This directory will contain user-provided DreamBot demo scripts as reference material for the AI agents.

Place complete, working DreamBot script examples here. The scripter agent uses these as patterns when generating new scripts.

## Expected Format

Each demo should be a complete `.java` file with:
- `@ScriptManifest` annotation
- Either `AbstractScript` or `TaskScript` implementation
- Comments explaining key patterns

## Suggested Demos

- Simple `AbstractScript` (e.g., power mining)
- `TaskScript` with banking (e.g., fishing + bank)
- `TaskScript` with combat + looting
- Anti-ban integration example
